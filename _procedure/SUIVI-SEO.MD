# Suivi des Procédures SEO

## 1. Objectif du document

Ce document sert de référentiel pour le suivi des actions SEO menées sur le site : outils utilisés, fréquence des vérifications, indicateurs suivis et historique des actions correctives.

---

## 2. Outils de suivi

| Outil | Lien | Usage principal |
|---|---|---|
| Google Search Console | https://search.google.com/u/1/search-console | Indexation, requêtes, couverture, Core Web Vitals, erreurs d'exploration |
| Bing Webmaster Tools | https://www.bing.com/webmasters | Indexation Bing, backlinks, mots-clés, diagnostics techniques |

> Ajouter ici tout autre outil utilisé (ex : Ahrefs, Semrush, Screaming Frog, Google Analytics...)

---

## 4. Checklist de suivi hebdomadaire

- [ ] Vérifier les erreurs de couverture dans Google Search Console
- [ ] Vérifier les erreurs de crawl dans Bing Webmaster Tools
- [ ] Contrôler les pages exclues de l'index
- [ ] Vérifier l'absence de nouvelles erreurs 404 / 5xx
- [ ] Contrôler les Core Web Vitals (LCP, INP, CLS)
- [ ] Vérifier les nouvelles impressions / clics anormaux (hausse ou chute)

---

## 5. Checklist de suivi mensuel

- [ ] Analyser l'évolution des positions sur les mots-clés cibles
- [ ] Comparer trafic organique mois vs mois précédent
- [ ] Identifier les pages en perte de positions
- [ ] Identifier les opportunités de mots-clés (requêtes en position 5-15)
- [ ] Vérifier la qualité et l'évolution du profil de backlinks
- [ ] Mettre à jour le tableau de suivi des mots-clés (section 7)
